First-time setup guide (5 minutes)
1

Create an Upstox Developer App

Go to account.upstox.com/developer/apps and click + NEW APP.

Nameanything (e.g. My Chart)
Redirect URIhttps://upstox.com
Descriptionany short text
Postback URLleave blank

Save. You’ll get a Client ID and Client Secret. Keep them handy.

2

Authorize — Get the Code

Open this URL in your browser (replace YOUR_CLIENT_ID):

https://api.upstox.com/v2/login/authorization/dialog?response_type=code&client_id=YOUR_CLIENT_ID&redirect_uri=https://upstox.com

Login with Upstox credentials, approve, then copy the ?code=XYZ from the URL bar.

3

Exchange Code for Token

Run in terminal (replace the 3 placeholders):

curl -X POST 'https://api.upstox.com/v2/login/authorization/token' \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  -H 'Accept: application/json' \
  -d 'code=YOUR_CODE&client_id=YOUR_CLIENT_ID&client_secret=YOUR_SECRET&redirect_uri=https://upstox.com&grant_type=authorization_code'

Copy the "access_token" value from the JSON response.

4

Paste & Save

Paste the token in the input above → Save. All tabs start pulling live data instantly.

Angel One SmartAPI setup
1

Create a SmartAPI App

Go to smartapi.angelone.in/new/apps and create an app.

Redirect URLhttp://127.0.0.1 (required, unused for login)
API Keynote it down after creation
2

Enable TOTP

Visit smartapi.angelone.in/enable-totp and copy the secret shown below the QR code.

3

Add Credentials & Run the Generator

Create data/angel-one-creds.json (gitignored), then run the bundled script — it logs in and writes angel_one_token into data/config.json automatically:

{
  "api_key": "YOUR_API_KEY",
  "client_code": "YOUR_CLIENT_ID",
  "pin": "YOUR_PIN",
  "totp_secret": "YOUR_TOTP_SECRET"
}

.venv/bin/python scripts/angel-one-auth.py
4

Paste & Save

The token loads from config.json on startup — or paste the JWT into the Angel One input above → Save. (Not yet used for live data; stored for upcoming broker support.)
