WHAT IT IS
A rules engine, not a predictor. The same CPR / VIX / PCR / trend logic you've already learned, automated into one click.
WHEN TO USE
9:00 AM daily, before market opens. Sets your bias for the day in 30 seconds. Re-check intraday whenever spot moves significantly.
WHAT IT ISN'T
Not a buy/sell signal. Not advice. Not live data. Always wait for a candle trigger at TC / BC / VWAP / Fib confluence before any trade.

How the score is computed:
• CPR shape (±1): Normal +1 / Inverted -1
• Price vs CPR band (±2): Above +2 / Inside 0 / Below -2
• CPR width (±1): Narrow boosts existing bias / Wide softens it
• VIX (±1): <13 boosts trend / >20 = -1 caution
• PCR (±1): >1.2 = +1 CE / <0.8 = -1 PE / 0.8–1.2 = neutral
• Higher-TF trend (±2): Strong Up +2 to Strong Down -2
• Buckets: ≥+4 STRONG CE / +1 to +3 CE BIAS / 0 NO TRADE / -1 to -3 PE BIAS / ≤-4 STRONG PE
