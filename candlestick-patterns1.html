CANDLE ANATOMY FOUNDATION

Every candlestick encodes 4 price points — master this before everything else

BULLISH CANDLE

Close > Open · Buyers won · GREEN

BEARISH CANDLE

Open > Close · Sellers won · RED

WICK / SHADOW MEANING

Long wick = price rejected that level.
Body = actual accepted movement.

KEY READING RULES
BODY SIZE
Large body = strong conviction. Small body = indecision.
WICK SIZE
Long wick = failed attempt. Buyers/sellers rejected.
CONTEXT
Same candle = different meaning at support vs resistance.
VOLUME
High volume confirms. Low volume = weak signal, skip.

API Connection UPSTOX

Token is stored only in your browser.
▸ Don't have a token? Get one in 5 minutes
  1. Log in to account.upstox.com/developer/apps and click + NEW APP.
  2. Fill the form:
    • Name: any (e.g. Live Chart)
    • Redirect URI: https://upstox.com (any valid URL works for personal use)
    • Description: any short text
    • Postback URL: leave blank
  3. Save. You'll get a Client ID and Client Secret.
  4. Open this URL in your browser (replace YOUR_CLIENT_ID): 
    https://api.upstox.com/v2/login/authorization/dialog?response_type=code&client_id=YOUR_CLIENT_ID&redirect_uri=https://upstox.com
  5. Login & approve. After redirect, the URL bar will show ?code=XYZ. Copy that code.
  6. Open a terminal and run (replace the 3 placeholders): 
    curl -X POST 'https://api.upstox.com/v2/login/authorization/token' \
  -H 'Content-Type: application/x-www-form-urlencoded' \
  -H 'Accept: application/json' \
  -d 'code=YOUR_CODE&client_id=YOUR_CLIENT_ID&client_secret=YOUR_SECRET&redirect_uri=https://upstox.com&grant_type=authorization_code'
  7. The response contains access_token. Copy and paste it above.
Note: Upstox tokens expire daily at 3:30 AM IST. Re-run steps 4–7 each morning. Token is stored in your browser's localStorage only — nothing leaves your machine except the API call to Upstox itself.
