# Legacy / archived prototypes

Design exploration files that have been superseded by the current
`candlestick-patterns.html`. Kept here for design-history reference,
**not** linked from the live app and **not** intended to be served.

## Inventory

| File | Date | Why archived |
|---|---|---|
| `candlestick-patterns.topnav-backup.html` | 2026-05-02 | Snapshot of the pre-sidebar version of the app, when navigation was a top tab strip. Replaced by the current collapsible-sidebar layout. |
| `font-preview.html` | 2026-05-03 | Side-by-side comparison of Inter, IBM Plex Sans, and Geist for body/mono. Decision: **IBM Plex Sans + IBM Plex Mono**. |
| `header-preview.html` | 2026-05-02 | Multiple header design options. Note: these use the old `--bull: #00e5a0` / `--bear: #ff2d55` palette before settling on the current `#09a86e` / `#c91f3a` financial-friendly tones. |
| `logo-preview.html` | 2026-05-03 | Logo concepts (bull, bear, candles). Decision: the 3-candle motif (red bear / yellow doji / green bull) — same design now lives in the favicon and PWA icons. |

## Safe to delete?

Yes — none of these are referenced from the live app. Keep them only if
you want to preview the alternatives or reference the rejected designs.
The current production palette and typography are the source of truth in
`candlestick-patterns.html`.
